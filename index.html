This game like a Rock,Paper and Sesor game. In this game you need to select one thing. After your selection, computer selects one thing automaticaly.

If you select Snake and conmpter select Water then you win the game. Because Snake will drink water. When computer select Gun then computer win this game. Because Gun will shoot the Snake.

If you select Water and conmpter select Gun then you win the game. Because Gun will drove in Water. When computer select Snake then computer win this game. Because Snake will drink the Water.

If you select Gun and conmpter select Snake then you win the game. Because Gun will shoot Snake. When computer select Water then computer win this game. Because Gun will drove the Water.
