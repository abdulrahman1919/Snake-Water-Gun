This game like a Rock-Paper-Scissor game. In this game you need to select one option. After your selection, computer selects one option automaticaly.

If you select Snake and computer select Water then you win the game. Because Snake will drink water. When computer select Gun then computer win this game. Because Gun will shoot the Snake.

If you select Water and computer select Gun then you win the game. Because Gun will drove in Water. When computer select Snake then computer win this game. Because Snake will drink in Water.

If you select Gun and computer select Snake then you win the game. Because Gun will shoot Snake. When computer select Water then computer win this game. Because Gun will drove in Water.

When both select same then match will tied.
